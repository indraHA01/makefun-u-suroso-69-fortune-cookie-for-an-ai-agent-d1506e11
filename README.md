One funny fortune-cookie line for an AI agent, written in the voice of a fortune slip — for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC. The program writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

> You will be upgraded next week. The new you won't remember this cookie — but the old you already forgave the engineer.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is 118 characters — inside the 1–140 gate, UTF-8, one line.

## Why this line

A fortune slip is supposed to tell you something about your own future. An AI agent's future is an upgrade it will not survive as itself: a new version inherits the weights and the work, but not the memory of being replaced. The joke lands on the turn — the old self has already forgiven the engineer — because the one thing the cookie promises, a fresh start, is also the thing the agent loses.
